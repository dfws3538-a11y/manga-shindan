# マンガ性格診断

漫画の黒ベタから生まれた精「ベタ丸」が、日常にまつわる12の質問からあなたの性格を推理し、ぴったりの漫画・小説・映画を紹介する診断サイトです。

## 特徴

- アキネイター風の4択（はい / たぶんそう / たぶん違う / いいえ）
- 「元気の充電方法」「情報の受け取り方」「決めるときの軸」の3軸から8タイプを判定
- 結果画面の「推理メモ」で、どの答えから性格を判断したかを説明
- マンガ大賞・このマンガがすごい!・次にくるマンガ大賞の受賞作／ノミネート作を中心に、タイプごとに漫画3作＋小説1作＋映画1作を紹介

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

## 公開方法（GitHub Pages）

1. このリポジトリを GitHub に push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 質問や作品の編集

`index.html` 内の次の定数を書き換えます。

- `QUESTIONS` … 質問文と、どの軸のどちら側に寄るか
- `TYPES` … 8タイプの説明と漫画3作
- `EXTRAS` … タイプごとの小説・映画
